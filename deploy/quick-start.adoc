= Inicio rápido de herramientas de ONTAP para VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configura ONTAP tools for VMware vSphere con esta guía de inicio rápido.

Completa primero estas tareas básicas para que ONTAP tools esté operativo para la configuración inicial y el aprovisionamiento. Luego completa las tareas opcionales según tu entorno y tus requisitos de protección.

En un primer momento, implementas ONTAP tools for VMware vSphere en una configuración de un solo nodo extra pequeña (XS) que proporciona servicios principales para los almacenes de datos NFS y VMFS. Si necesitas contenedores adicionales por servicio, mayor resiliencia o almacenes de datos vVols y alta disponibilidad (HA), completa primero este flujo de trabajo y luego continúa con la ampliación. Para más información, consulta la link:../deploy/ha-workflow.html["Flujo de trabajo de implementación DE ALTA disponibilidad"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Una"] Planifique su implementación
[role="quick-margin-para"]
Comprueba que tu entorno esté preparado para una implementación compatible. Comprueba que tus versiones de vSphere, ONTAP y del host ESXi sean compatibles con la versión de ONTAP tools. Asigna suficiente CPU, memoria y espacio en disco. Según tus reglas de seguridad, puede que necesites configurar cortafuegos u otros controles de seguridad para permitir el tráfico de red.

[role="quick-margin-para"]
Asegúrate de que vCenter Server esté instalado y sea accesible.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dos"] Ponga en marcha herramientas de ONTAP para VMware vSphere
[role="quick-margin-para"]
Implementa el appliance de ONTAP tools para establecer los servicios base para los datastores NFS y VMFS.

[role="quick-margin-para"]
Si planeas ampliar tu implementación para los almacenes de datos vVols y la alta disponibilidad (HA), completa primero este flujo de trabajo. En ONTAP tools for VMware vSphere 10.6, la incorporación en caliente de CPU y la memoria conectable en caliente están habilitadas de forma predeterminada.

[role="quick-margin-para"]
Durante la implementación, revisa con atención los campos de *Personalizar plantilla*, especialmente el nombre de host, el uso de la dirección IP de ONTAP tools y los requisitos de DNS.

[role="quick-margin-list"]
* link:../deploy/ontap-tools-deployment.html["Ponga en marcha herramientas de ONTAP para VMware vSphere"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tres"] Regístrate e instala el complemento de cliente de vCenter
[role="quick-margin-para"]
Añade una instancia de vCenter Server para registrar el complemento de cliente de vCenter y aplicar los privilegios y roles necesarios. Cuando añades una instancia de vCenter Server, ONTAP tools registra el complemento remoto, aplica privilegios personalizados del complemento y de la API, crea roles personalizados y añade un acceso directo al complemento en la interfaz de usuario de vSphere.

[role="quick-margin-list"]
* link:../configure/add-vcenter.html["Agregar instancias de vCenter Server a las herramientas de ONTAP"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Cuatro"] Configura los backends de almacenamiento
[role="quick-margin-para"]
Conecta los recursos de almacenamiento de ONTAP para que ONTAP tools pueda aprovisionar y gestionar los almacenes de datos. Añade un backend de almacenamiento a un clúster ONTAP. En entornos multitenant donde un servidor vCenter está asociado con un SVM de un tenant, usa ONTAP tools Manager para añadir el clúster. Luego asocia el backend de almacenamiento con el servidor vCenter para crear una asignación global para esa instancia de vCenter.

[role="quick-margin-para"]
Agrega backends de almacenamiento local con credenciales de clúster o SVM usando la interfaz de ONTAP tools. Estos backends de almacenamiento están limitados a un solo vCenter. Cuando usas credenciales de clúster localmente, las SVM asociadas se asignan automáticamente al vCenter para la gestión de vVol o VMFS. Para la gestión de VMFS, incluyendo SRA, ONTAP tools admite credenciales de SVM sin requerir un clúster global.

[role="quick-margin-list"]
* link:../configure/add-storage-backend.html["Añada un back-end de almacenamiento"]
* link:../configure/associate-storage-backend.html["Asocie el back-end de almacenamiento a una instancia de vCenter Server"]

En los sistemas ONTAP, haz la relación entre los clústeres y las SVM necesarios y luego configura la protección en ONTAP tools. Esta opción solo se aplica a los almacenes de datos VMFS.

[role="quick-margin-para"]
La copia de seguridad está activada de forma predeterminada en ONTAP tools for VMware vSphere 10.6 y se ejecuta cada 10 minutos.
