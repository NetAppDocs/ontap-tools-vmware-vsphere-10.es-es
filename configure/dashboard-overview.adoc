= Conoce el panel de control de las ONTAP tools for VMware vSphere
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Selecciona el icono del complemento ONTAP tools for VMware vSphere en la sección de accesos directos del cliente vCenter para abrir el panel, que resume el estado del complemento, los datastores y los datos del servidor vCenter.

En el modo vinculado mejorado (ELM), aparece el menú desplegable de vCenter Server.  Seleccione un servidor vCenter para ver sus datos.  El menú desplegable está disponible en todas las vistas de lista del complemento. Al seleccionar un vCenter Server en una página, permanece igual al cambiar de pestaña en el complemento.image:../media/remote-plugin-dashboard.png["Información general del panel de control"]

Desde la página de resumen, puedes ejecutar la acción *Discovery* para detectar backends de almacenamiento, hosts, almacenes de datos recién añadidos o actualizados, y el estado de protección o las relaciones a nivel de vCenter. Ejecuta un descubrimiento bajo demanda sin esperar al descubrimiento programado.

Si añades un nuevo host a un clúster de hosts protegidos, la configuración de protección pasa a ser *Parcialmente protegido*.

Para solucionar este estado, abre *Modificar configuración del clúster*, asigna el host al sitio correcto (origen o destino) y selecciona *Modificar*.


NOTE: El botón *Detección* solo se activa si tienes el privilegio necesario para realizar la detección.

Una vez enviada la solicitud de descubrimiento, puede seguir el progreso de la acción en el panel de tareas recientes.

La consola tiene varias tarjetas que muestran diferentes elementos del sistema. La siguiente tabla muestra las diferentes cartas y lo que representan.

|===


| *Tarjeta* | *Descripción* 


| Estado | La tarjeta de estado muestra el número de backends de almacenamiento y el estado de salud general de los backends de almacenamiento y del VASA Provider. El estado de los backends de almacenamiento muestra *Saludable* cuando todos los estados de los backends de almacenamiento son normales y muestra *No saludable* si algún backend de almacenamiento tiene un problema (estado desconocido/inaccesible/degradado). Selecciona el tool tip para abrir los detalles del estado de los backends de almacenamiento. Puedes seleccionar cualquier backend de almacenamiento para ver más detalles. El enlace *Other VASA Provider states* muestra el estado actual del VASA Provider que está registrado en el servidor vCenter. 


| Back-ends de almacenamiento: Capacidad | Esta tarjeta muestra la capacidad agregada utilizada y disponible de todos los backends de almacenamiento para la instancia de vCenter Server seleccionada. Para los sistemas de almacenamiento ASA r2, los datos de capacidad no se muestran porque el almacenamiento está desagregado. 


| Equipos virtuales | Esta ficha muestra las 10 máquinas virtuales principales ordenadas según un indicador de rendimiento. Puedes seleccionar el encabezado para ordenar las 10 máquinas virtuales principales según el indicador seleccionado, ya sea en orden ascendente o descendente. Los cambios de ordenación y filtrado realizados en la ficha se mantienen hasta que modifiques o borres la caché del navegador. 


| Almacenes de datos | Esta tarjeta muestra los 10 almacenes de datos principales ordenados según una métrica de rendimiento. Puedes seleccionar el encabezado para ordenar los 10 almacenes de datos principales según la métrica seleccionada, ya sea en orden ascendente o descendente. Los cambios de ordenación y filtrado realizados en la tarjeta se mantienen hasta que cambies o borres la caché del navegador. Usa la lista desplegable de tipo de almacén de datos para seleccionar el tipo de almacén: NFS, VMFS o vVols. 


| Tarjeta de cumplimiento de normativas del host ESXi | Esta tarjeta muestra si todos los hosts ESXi (para el vCenter seleccionado) siguen la configuración recomendada de host NetApp por grupo o categoría. Puedes seleccionar el enlace *Aplicar configuración recomendada* para aplicar la configuración recomendada. Puedes seleccionar el estado de cumplimiento de los hosts para ver la lista de hosts. 
|===
