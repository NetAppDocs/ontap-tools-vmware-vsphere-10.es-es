= Configura el acceso a la red en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
De forma predeterminada, ONTAP tools añade automáticamente todas las direcciones IP detectadas en el host ESXi a la política de exportación, a menos que configures el acceso a la red. Puedes modificar la política de exportación para permitir el acceso solo desde direcciones IP específicas; las operaciones de montaje fallan para los hosts ESXi excluidos.

.Pasos
. Inicie sesión en el cliente de vSphere.
. Selecciona *NetApp ONTAP tools* en la página de accesos directos en la sección de complementos.
. En el panel izquierdo de las herramientas de ONTAP , vaya a *Configuración* > *Administrar acceso a la red* > *Editar*.
+
Para añadir varias direcciones IP, separa la lista con comas, rangos, notación Classless Inter-Domain Routing (CIDR) o una combinación de los tres.

. Seleccione *Guardar*.
