= Consola de mantenimiento de ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
La consola de mantenimiento de las ONTAP tools for VMware vSphere le permite gestionar la configuración de aplicaciones, sistemas y redes.  Puede actualizar las contraseñas de administrador y mantenimiento, generar paquetes de soporte, configurar los niveles de registro, administrar la configuración TLS y habilitar diagnósticos remotos.

Después de implementar ONTAP tools for VMware vSphere, si no puedes acceder a la consola de mantenimiento, instala VMware Tools desde vCenter Server. Inicia sesión usando el `maint` nombre de usuario y la contraseña que configuraste durante la implementación. Usa *nano* para editar archivos en la consola de mantenimiento o en la consola de inicio de sesión root.


NOTE: Establece una contraseña para el usuario  `diag` cuando actives el diagnóstico remoto.

Utiliza la pestaña *Resumen* de tus herramientas ONTAP implementadas para VMware vSphere para acceder a la consola de mantenimiento. Selecciona image:../media/launch-maintenance-console.gif["Botón de reproducción"] para iniciar la consola de mantenimiento.
