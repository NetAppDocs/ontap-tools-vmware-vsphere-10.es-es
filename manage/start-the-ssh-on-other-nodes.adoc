= Inicia SSH en otros nodos de ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debe iniciar SSH en otros nodos antes de actualizar.

.Antes de empezar
Habilite la extensión VASA Provider para su instancia de vCenter Server.

.Acerca de esta tarea
Repita este procedimiento en cada nodo antes de actualizar.

.Pasos
. Inicia sesión en el servidor vCenter.
. Ubica la máquina virtual del nodo de ONTAP tools e inicia la consola web.
. Inicia sesión usando las credenciales de `maint`.
. Introduzca `4` Para seleccionar Support and Diagnostics.
. Introduzca `1` Para seleccionar el shell de diagnóstico de Access.
. Introduzca `y` para continuar.
. Ejecute el comando _sudo systemctl restart ssh_.
