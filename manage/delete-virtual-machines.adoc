= Limpia las configuraciones VASA en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sigue estos pasos para completar la limpieza de VASA en ONTAP tools.


NOTE: Elimina cualquier almacén de datos de vVols antes de iniciar la limpieza de VASA.

.Pasos
. Abre `\https://OTV_IP:8143/Register.html` para dar de baja el complemento.
. Compruebe que el plugin ya no esté disponible en vCenter Server.
. Apaga las ONTAP tools for VMware vSphere virtual machine (VM).
. Elimine las herramientas de ONTAP para VMware vSphere VM.
