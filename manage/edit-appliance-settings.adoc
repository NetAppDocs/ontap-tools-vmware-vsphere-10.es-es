= Amplía las herramientas de ONTAP y habilita la alta disponibilidad
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utiliza ONTAP tools Manager para ampliar la capacidad de tu appliance y configurar la alta disponibilidad (HA). De forma predeterminada, ONTAP tools for VMware vSphere se implementa como una configuración de un solo nodo sin alta disponibilidad.

.Antes de empezar
* Asegúrate de que tu plantilla OVA coincida con la versión de Node 1 (el nodo de implementación inicial).
* Activa la incorporación en caliente de CPU y la conexión en caliente de memoria en el hipervisor. Estas funciones son necesarias para escalar el appliance y habilitar HA. Para ONTAP tools 10.6 y versiones posteriores, estas funciones están habilitadas por defecto. Para versiones anteriores, habilita estas funciones antes de escalar o habilitar HA.
* En vCenter Server, configura el nivel de automatización del Disaster Recovery Service (DRS) en parcialmente automatizado. Vuelve a totalmente automatizado después de que se complete la implementación de HA.
+

NOTE: Solo puedes aumentar el tamaño del nodo, no reducirlo. Las implementaciones Extra small (XS) limitan ciertos servicios.



.Pasos
. Inicia ONTAP tools Manager: `\https://<ONTAPtoolsIP>:8443/virtualization/ui/`
. Inicia sesión con tus credenciales de administrador de ONTAP tools.
. Selecciona *Editar configuración del dispositivo* en la sección de resumen.
. En la sección *Configuración*, selecciona el nuevo tamaño del nodo y activa el interruptor HA para habilitar la alta disponibilidad.
. En la página *Configuración de HA*, comprueba lo siguiente:
+
** La biblioteca de contenidos se encuentra en el mismo vCenter Server donde se ejecutarán las máquinas virtuales de ONTAP tools.
** Las máquinas virtuales de las ONTAP tools se implementan en un clúster o en un pool de recursos, no directamente en un host ESXi.
+

IMPORTANT: Después de habilitar la alta disponibilidad (HA), no puedes volver a una configuración de un solo nodo sin HA.



. En la sección *Configuración de HA*, introduce los datos de red de los nodos 2 y 3. ONTAP tools admite tres nodos en modo HA.
+
ONTAP tools rellena automáticamente la mayoría de los campos con la configuración de red de Node 1. Puedes editar estos valores antes de completar el asistente. Las entradas de dirección IPv6 solo están disponibles si IPv6 está habilitado en el nodo de gestión. Asegúrate de que cada host ESXi aloje solo una ONTAP tools VM.

. Revisa el resumen y haz clic en *Guardar*.


.Resultado
El dispositivo inicia el proceso de escalabilidad y la activación de alta disponibilidad (HA). Supervisa el progreso en la página *Resumen* o realiza un seguimiento del trabajo desde la vista *Trabajos* usando el ID del trabajo.

Si la implementación de HA falla con el estado 'Nuevo', elimina la máquina virtual que ha fallado en vCenter y vuelve a intentarlo.

Consulta la pestaña *Alertas* para ver si hay alguna advertencia o problema durante el proceso.
