= Desmonta los almacenes de datos NFS y VMFS en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utiliza esta tarea para desmontar un almacén de datos NFS o VMFS de los hosts ESXi. No se admite el desmontaje de almacenes de datos a nivel de clúster a través de la interfaz de usuario ni de las API.

A partir de ONTAP tools 10.6, la operación de desmontaje está bloqueada para los almacenes de datos VMFS protegidos.

.Pasos
. Inicie sesión en el cliente de vSphere.
. Haz clic con el botón derecho del ratón en un objeto de almacén de datos NFS o VMFS y selecciona *Desmontar almacén de datos*.
+
El cliente vSphere abre un cuadro de diálogo y muestra los hosts ESXi que montan el almacén de datos. Si el almacén de datos está protegido, ONTAP tools bloquea la solicitud y muestra un mensaje que indica que el almacén de datos está bajo protección y no se puede desmontar.

. Seleccione uno o varios hosts ESXi para desmontar el almacén de datos.
+
No es posible desmontar el almacén de datos de todos los hosts. La interfaz de usuario sugiere que se utilice la operación de eliminación del almacén de datos en su lugar.

. Seleccione el botón *Desmontar*.
+
La opción *Desmontar almacén de datos* solo está disponible cuando el host se traslada fuera del clúster de hosts protegidos.




NOTE: Si un almacén de datos está protegido, debes desactivar la protección antes de poder desmontarlo.
