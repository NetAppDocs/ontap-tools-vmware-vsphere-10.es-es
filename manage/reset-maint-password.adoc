= Restablece la contraseña de la consola de mantenimiento de las ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Durante el reinicio de un sistema operativo invitado, el menú de GRUB muestra una opción para restablecer la contraseña de usuario de la consola de mantenimiento. Utiliza esta opción para actualizar la contraseña en la VM. Después de restablecer la contraseña, la VM se reinicia. En una implementación HA, el sistema actualiza automáticamente la contraseña en las otras dos VMs después del reinicio.


NOTE: Para una implementación de ONTAP tools for VMware vSphere HA, cambia la contraseña de usuario de la consola de mantenimiento en el nodo de gestión de ONTAP tools (node1).

.Pasos
. Inicie sesión en vCenter Server
. Haz clic con el botón derecho del ratón sobre la máquina virtual y selecciona *Energía* > *Reiniciar el sistema operativo invitado*. Durante el reinicio del sistema, aparece la siguiente pantalla: image:../media/maint-console-password.png["Restablezca la contraseña del usuario de mantenimiento"]
+
Tienes cinco segundos para elegir una opción. Pulsa cualquier tecla para detener la cuenta atrás y pausar el menú de GRUB.

. Seleccione la opción *Restablecer contraseña del usuario de mantenimiento*. Se abre la consola de mantenimiento.
. En la consola, ingrese y confirme la nueva contraseña.  Tienes tres intentos.  El sistema se reinicia después de ingresar exitosamente la nueva contraseña.
. Presione *Enter* para continuar.  El sistema actualiza la contraseña en la VM.



NOTE: Al encender la máquina virtual, aparece el mismo menú de GRUB. Utiliza la opción de restablecer contraseña únicamente con *Restart Guest OS*.
