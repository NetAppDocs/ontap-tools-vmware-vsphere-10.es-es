= Ver los detalles de almacenamiento de las máquinas virtuales en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utiliza la vista de almacenamiento para ver los vVols asociados con una máquina virtual.


NOTE: Esta vista se aplica a las máquinas virtuales con al menos un disco de un almacén de datos vVols gestionado ONTAP tools for VMware vSphere .

.Pasos
. Desde vSphere Client, vaya a la máquina virtual.
. Seleccione la pestaña *Monitor* en el panel derecho.
. Selecciona *NetApp ONTAP tools* > *Storage*. Los detalles de *Storage* aparecen en el panel derecho. Puedes ver la lista de vVols en la máquina virtual.
+
Puedes utilizar la opción *Manage Columns* para ocultar o mostrar columnas.
