= Vistas de almacenamiento ONTAP para datastores en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utiliza la página ONTAP Storage en la pestaña *Configurar* para ver la información de los datastores y volúmenes.

.Pasos
. En el inventario de vSphere Client, selecciona el almacén de datos.
. Seleccione la pestaña *Configure* en el panel derecho.
. Seleccione * Herramientas NetApp ONTAP * > * Almacenamiento ONTAP *. La vista cambia según el tipo de almacén de datos.  Consulte la tabla a continuación:


|===


| *Tipo de almacén de datos* | *Información disponible* 


| Almacenes de datos NFS | La página *Detalles de almacenamiento* contiene backends de almacenamiento, agregados y información de volúmenes. La página *Detalles de NFS* contiene datos relacionados con el almacén de datos NFS. Nota: si el valor de nconnect se cambia fuera de ONTAP tools, el valor que se muestra en ONTAP tools podría no reflejar ese cambio externo. 


| Almacenes de datos de VMFS | La página *Detalles de almacenamiento* contiene detalles sobre el backend de almacenamiento, el agregado, el volumen y la zona de disponibilidad de almacenamiento (SAZ). La página *Detalles de la unidad de almacenamiento* contiene detalles sobre la unidad de almacenamiento. 


| Almacenes de datos de vVols | Enumera todos los volúmenes. Puede expandir o eliminar almacenamiento desde el panel de almacenamiento de ONTAP . Las herramientas ONTAP no admiten esta vista para los almacenes de datos vVols basados ​​en el sistema ASA r2. 
|===
.Resultado
Puedes consultar los detalles del almacén de datos en ONTAP según el tipo de almacén de datos que elijas.
