= Vistas de almacenamiento ONTAP para datastores en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP tools for VMware vSphere muestra detalles del lado de ONTAP para los almacenes de datos y sus volúmenes en la pestaña *Configurar*, incluyendo el backend de almacenamiento, el agregado y los detalles del volumen para cada tipo de almacén de datos.

.Pasos
. En el inventario de vSphere Client, selecciona el almacén de datos.
. Seleccione la pestaña *Configure* en el panel derecho.
. Seleccione * Herramientas NetApp ONTAP * > * Almacenamiento ONTAP *. La vista cambia según el tipo de almacén de datos.  Consulte la tabla a continuación:


|===


| *Tipo de almacén de datos* | *Información disponible* 


| Almacén de datos NFS | La página *Detalles de almacenamiento* contiene información sobre el backend de almacenamiento, el agregado y el volumen. La página *Detalles de NFS* contiene datos relacionados con el datastore NFS. Nota: si se modifica el valor de nconnect fuera de ONTAP tools, es posible que el valor que se muestra en ONTAP tools no refleje ese cambio externo. 


| Almacenes de datos de VMFS | La página *Detalles de almacenamiento* contiene información sobre el backend de almacenamiento, el agregado, el volumen y la zona de disponibilidad de almacenamiento (SAZ). La página *Detalles de la unidad de almacenamiento* contiene información sobre la unidad de almacenamiento. 


| Almacenes de datos de vVols | La página muestra todos los volúmenes. Puedes ampliar o eliminar almacenamiento desde el panel de almacenamiento de ONTAP. ONTAP tools for VMware vSphere no admite esta vista para los datastores basados en sistemas ASA r2 vVols. 
|===
.Resultado
Puedes consultar los detalles del almacén de datos en ONTAP según el tipo de almacén de datos que elijas.
