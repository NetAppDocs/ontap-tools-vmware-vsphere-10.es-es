= Actualiza las credenciales de vCenter Server en ONTAP tools
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utiliza la consola de mantenimiento para actualizar las credenciales de la instancia de vCenter Server.

.Antes de empezar
Necesitas las credenciales de usuario de mantenimiento.

.Acerca de esta tarea
Si modificó las credenciales del servidor vCenter después de la implementación, actualícelas siguiendo este procedimiento.

.Pasos
. Inicia sesión en el servidor vCenter.
. Busca la máquina virtual de ONTAP tools e inicia la consola web.
. Inicia sesión usando las credenciales de `maint`.
. Acceda `2` a para seleccionar Menú de configuración del sistema.
. Ingresar `8` para cambiar las credenciales de vCenter.
