= Novedades de las herramientas de ONTAP para VMware vSphere 10.6
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Descubre las nuevas funciones y mejoras en ONTAP tools for VMware vSphere 10.6.



[[granular-datastore-protection]]
== Protección granular del datastore

ONTAP tools 10.6 introduce la protección a nivel de almacén de datos, así que puedes aplicar protección a los almacenes de datos seleccionados en vez de a todo el clúster de hosts.

Entre las principales mejoras se incluyen:

* Protección a nivel de almacén de datos para sistemas ONTAP y sistemas ASA r2
* Dúplex con conmutación automática al respaldo (AFD) y políticas de protección asíncronas
* Compatibilidad con almacenes de datos VMFS de iSCSI y FC
* Grupos jerárquicos de consistencia y configuraciones de fan-out
* Control sobre la pertenencia a grupos de consistencia eligiendo qué almacenes de datos proteger juntos
* Configuraciones de protección AFD uniformes y no uniformes
* Posibilidad de modificar la protección añadiendo o eliminando almacenes de datos y hosts
* Flujo de trabajo de protección de almacenes de datos en el complemento vCenter
* Ruta de actualización de la protección de clúster de hosts a la protección a nivel de almacén de datos




[[audit-logging]]
== Registro de auditoría

ONTAP tools 10.6 añade el registro de auditoría para mejorar la seguridad y la trazabilidad operativa.

El registro de auditoría incluye:

* Todas las llamadas a la API de REST que no sean GET, incluidos los detalles de la solicitud y la respuesta
* Trabajos de detección, trabajos de paquetes de AutoSupport, trabajos de limpieza y operaciones de la consola de mantenimiento
* Protección de la integridad de los archivos de registros de auditoría, incluidas las alertas de manipulación y eliminación
* Compatibilidad con el reenvío de syslog


Estas actualizaciones admiten los requisitos de cumplimiento y seguridad.



[[nconnect-support-for-nfs-datastores]]
== Compatibilidad de nconnect con los almacenes de datos NFS

ONTAP tools 10.6 añade compatibilidad con nconnect para los almacenes de datos NFS de VMware, permitiendo múltiples conexiones TCP paralelas entre los hosts ESXi y los almacenes de datos NFS de ONTAP.

Esta versión es compatible con:

* nconnect para almacenes de datos NFSv3 durante el aprovisionamiento
* nconnect para almacenes de datos NFSv4.1 durante el aprovisionamiento con vCenter 8.0U3 y versiones posteriores
* Modificación del valor máximo de nconnect en los hosts ESXi


Esto ayuda a mejorar el rendimiento y el rendimiento del almacén de datos NFS para cargas de trabajo con varias máquinas virtuales.



[[smaller-default-deployment-with-xs-profile]]
== Implementación predeterminada más reducida con el perfil XS

ONTAP tools 10.6 introduce un perfil de implementación predeterminado más pequeño, extra-small (XS), para reducir la sobrecarga de recursos y simplificar la implementación inicial.

Las mejoras incluyen:

* XS como configuración predeterminada para la implementación inicial
* Implementación de OVA con ajustes de hardware predeterminados optimizados
* Compatibilidad con el aprovisionamiento de almacenes de datos, la protección, la activación del servicio SRA y el modo HA con XS
* Cuatro perfiles de implementación disponibles en la interfaz de usuario de Manager: extra pequeño (XS), pequeño (S), mediano (M) y grande (L)


Este modelo ofrece una inversión inicial menor y una trayectoria clara de ampliación.



[[ease-of-deployment-improvement]]
== Mejora de la facilidad de implementación

ONTAP tools 10.6 habilita de forma predeterminada la incorporación en caliente de CPU y la conexión en caliente de memoria para las nuevas implementaciones de la máquina virtual principal de ONTAP tools.

De este modo, ya no es necesario activar manualmente estos ajustes antes o después de la implementación.



[[protection-workflow-improvement]]
== Mejora del flujo de trabajo de protección

ONTAP tools 10.6 elimina la necesidad de activar manualmente la detección de almacenamiento cuando los clústeres ONTAP no están disponibles, simplificando los flujos de trabajo de protección.



[[platform-and-interoperability-qualification]]
== Cualificación de la plataforma e interoperabilidad

ONTAP tools 10.6 amplía la compatibilidad de la plataforma y la interoperabilidad con las principales versiones de ONTAP y VMware, lo que permite una integración perfecta del almacenamiento NetApp en entornos VMware.

Esta versión se adapta a las configuraciones actuales de la plataforma ONTAP y a las versiones de VMware, reduciendo la complejidad operativa durante las actualizaciones de la plataforma y las renovaciones de la pila de VMware.



[[supportability-enhancements]]
== Mejoras en la capacidad de soporte

ONTAP tools 10.6 mejora la resolución de problemas y la gestión del ciclo de vida.

Las novedades clave incluyen:

* Eliminación forzada de entradas de vCenter inaccesibles u obsoletas
* Migración de `ntpd` a `chronyd` para la sincronización horaria, con migración automática de la configuración existente del servidor NTP durante la actualización
* Opción de la consola de mantenimiento para renovar los certificados de los servicios internos, incluso después de su expiración
* Compatibilidad tanto con servidores NTP tradicionales como con servidores chrony basados en RHEL a través del protocolo NTP estándar (puerto UDP 123)


Para obtener la información más reciente sobre la compatibilidad entre versiones, consulta https://mysupport.netapp.com/matrix["Herramienta de matriz de interoperabilidad de NetApp"^].
