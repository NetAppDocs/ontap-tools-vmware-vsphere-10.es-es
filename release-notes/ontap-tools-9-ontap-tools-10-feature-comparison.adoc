= Comparación de funciones de ONTAP tools for VMware vSphere por versión
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Descubre por qué migrar de ONTAP tools for VMware vSphere 9 a ONTAP tools for VMware vSphere 10.2 o una versión posterior puede ser la opción más adecuada para tu entorno.


NOTE: Para obtener la información más reciente sobre compatibilidad, consulta https://mysupport.netapp.com/matrix["Herramienta de matriz de interoperabilidad de NetApp"^].

Para consultar la información más reciente sobre el fin del soporte técnico de las ONTAP tools 9.x, visita https://mysupport.netapp.com/site/info/version-support["Compatibilidad con versiones de software"^].

[cols="20%,25%,30%"]
|===
| Característica | Herramientas ONTAP 9.13 | Herramientas ONTAP 10.2 en adelante 


| Propuesta de valor clave | Optimiza y simplifica las operaciones desde el día 0 hasta el día 2 con funcionalidades mejoradas de seguridad, cumplimiento y automatización. Solo admite un vCenter Server por appliance de ONTAP tools. | Ampliación de la compatibilidad para incluir FC para VMFS y NVMe-oF solo para VMFS. Facilidad de uso para NetApp SnapMirror, configuración sencilla para clústeres de almacenamiento metro de vSphere y compatibilidad con VMware Live Site Recovery en tres sitios. Admite múltiples instancias de vCenter Server por appliance de ONTAP tools, lo que reduce el número de appliances y los requisitos generales de recursos. 


| Calificación de liberación de ONTAP | ONTAP 9.9.1 a ONTAP 9.16.1 | ONTAP 9.12.1 a 9.15.1 para ONTAP tools 10.2. ONTAP 9.14.1, 9.15.1, 9.16.0 y 9.16.1 para ONTAP tools 10.3. ONTAP 9.14.1, 9.15.1, 9.16.0 y 9.16.1 para ONTAP tools 10.4. ONTAP 9.16.1P3 y versiones posteriores es obligatorio para ONTAP tools 10.4 cuando usas sistemas ASA r2. ONTAP 9.15.1, 9.16.1 y 9.17.0 para ONTAP tools 10.5; ONTAP 9.16.1, 9.17.1, 9.18.1 y 9.19.1, y las versiones ASA r2 9.16.1P3, 9.17.1, 9.18.1 y 9.19.1 para ONTAP tools 10.6. 


| Compatibilidad con versiones de VMware | vSphere 7.x-8.x VMware Site Recovery Manager (SRM) 8.5 a VMware Live Site Recovery 9.0 | vSphere 7.x-8.x vSphere 9.0 a partir de ONTAP tools 10.5 en adelante, VMware Site Recovery Manager (SRM) 8.7 a VMware Live Site Recovery 9.0, 9.0.1, 9.0.2, 9.0.3 y 9.0.4 


| Soporte de protocolo | Almacenes de datos NFS y VMFS: NFS (v3 y v4.1), VMFS (iSCSI y FCP) | Almacenes de datos NFS y VMFS: NFS (v3 y v4.1), VMFS (iSCSI/FCP/NVMe-TCP y NVMe-FC) 


| Escalabilidad | Hosts y máquinas virtuales: 300 hosts, hasta 10 000 máquinas virtuales Almacenes de datos: 600 NFS, hasta 50 VMFS | Hosts y máquinas virtuales: 600 hosts 


| Observabilidad | Paneles de rendimiento, capacidad y cumplimiento del host Informes dinámicos de máquinas virtuales y almacenes de datos | Paneles de control actualizados sobre rendimiento, capacidad y cumplimiento del host Informes dinámicos de máquinas virtuales y almacenes de datos 


| Protección de datos | Replicación de SRA para VMFS y NFS.  Integración SCV e interoperable para backup. | Replicación SRA para almacenes de datos iSCSI VMFS y NFS v3, protección en tres sitios que combina SMAS y VMware Live Site Recovery. Compatibilidad de SRA con FCP y VMFS. Protección granular de almacenes de datos y gestión de grupos de consistencia desde ONTAP tools 10.6. *NOTA:* En ONTAP tools 10.x, SRM admite sitios compartidos, lo que permite una mayor escalabilidad y un mejor rendimiento. 


| Soporte del proveedor de VASA | VASA 4.0 | VASA 3.0 
|===
